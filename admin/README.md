# Skill Hub Dashboard

Buatkan saya halaman dengan nama brand skill pil (https://skillpillv2.masterb.id/)

dengan isian halaman: 

- dashboard monitoring user/omzet/list data

- crud untuk katalog skill (gambar/judul/tampilan landing page/hargaw/label/isian produk digital)

- list user dengan jumlah pesanan

- monitoring leader board
